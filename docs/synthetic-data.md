# Synthetic data

**All records in this repository are fictional. No PHI. Not clinical decision support.**
This package supports a research proof of concept for what a Microsoft IQ intelligence layer could
look like in a research-focused academic medical center. It was not copied from patient records,
customer environments, institutional documents, protected protocols, licensed clinical guidelines,
production telemetry, or public trial records. Any resemblance to a real person or organization is
coincidental.

## Generation

`data/fabric/generate.py` writes all 16 Fabric CSV tables. It is:

- **Deterministic**: all synthetic variation uses `random.Random("amc-iq-fabric-2026:<entity-key>")`.
  Repeated runs produce byte-identical output with canonical LF line endings regardless of OS or
  Python hash seeding.
- **Idempotent**: running it twice produces the same files.
- **Hero-preserving**: `PT-1042` through `PT-1045` and their four original trials are written from
  pinned literal values. The generator asserts the hero CrCl trajectory and trial threshold before writing.

```powershell
.\.venv\Scripts\python data/fabric/generate.py
```

## Validate consistency

```powershell
.\.venv\Scripts\python tools/validate_consistency.py
```

Checks: every `PT-####` and `NCT########` token in the package resolves to a registry entry;
hero patient and trial appear in the expected layers; referential integrity across all 16 tables;
hero rows are unchanged.

## Reset

For a local reset, re-run the generator: it overwrites all 16 generated CSVs with identical
deterministic output. The hand-authored files in `data/foundry_docs/`, `data/work/`, and `data/web/`
are not generated; edit and commit them directly if corrections are needed.

For a deployed proof-of-concept reset, re-run the relevant provisioning and seed commands in
`agent/provisioning/live/` after resetting the target Foundry, Fabric, and Search resources.

## Fictional trial identifiers

All ten trial identifiers use the reserved project range `NCT99xxxxxx`. On 2026-07-25, each
identifier returned HTTP 404 from the ClinicalTrials.gov v2 study endpoint, confirming that none
was registered. Recheck immediately before publication because registry contents can change.

```powershell
$ids = @('NCT99004324', 'NCT99004325', 'NCT99004326', 'NCT99004401')
foreach ($id in $ids) {
  curl.exe -o NUL -s -w "%{http_code} $id`n" "https://clinicaltrials.gov/api/v2/studies/$id"
}
# Expected: 404 for all
```

## What the proof of concept does not contain

- Real patient records, MRNs, or clinical notes.
- Real genomics, pathology, or lab results.
- Licensed clinical guideline text or proprietary clinical pathways.
- Real trial protocols or IRB documents.
- Production telemetry, logs, or prompt/completion dumps.
- Real employee names, email addresses, or internal meeting notes.
- Transcriptions or close paraphrases of protected source material.

## Intentional ambiguity

The hero thread is designed so the answer is not obvious:
- CrCl 48 mL/min (latest) vs. >= 50 threshold, below by 2, prior reading was 55.
- `AMD-2` softens the platinum exclusion from automatic `not_met` to `uncertain` (PI confirmation).
- The borderline state drives `likely_eligible_pending` and the repeat-lab plus PI-review action.
