One clinical question. Four intelligence layers. One governed next step.

AMC IQ is a mock-first demonstration of Microsoft's IQ intelligence layer applied to precision-oncology trial readiness. It brings institutional knowledge, structured clinical data, care-team workflow, and external evidence into one cited assessment.

The scenario

A trial-readiness question that crosses data boundaries.

"Patient with metastatic NSCLC, EGFR exon 20 insertion, prior platinum therapy, ECOG 1, CrCl 48. The open trial mentions renal thresholds and prior-therapy exclusions. Is the patient eligible, and what should the care team do next?"

A useful answer needs more than search. It must reconcile protocol language, patient facts, institutional policy, current workflow, and public evidence while surfacing uncertainty instead of hiding it.

Four layers, one assessment

Each source answers a different part of the question.

01

Foundry IQ

Grounds the assessment in protocols, amendments, pathology, genomics, consent policy, and institutional operating procedures.

Institutional knowledge
02

Fabric IQ

Retrieves structured patient, laboratory, treatment, trial, enrollment, and scheduling facts through a Fabric Data Agent.

Structured clinical context
03

Work IQ

Adds coordinator ownership, tumor-board context, open tasks, PI availability, and the care team's current operating state.

Workflow context
04

Web IQ

Supplies current public evidence through a Bing-backed Azure AI Search knowledge source. It is a scenario stand-in for the limited-access Web IQ product.

External grounding

How the answer is built

Parallel retrieval. Explicit uncertainty. Human review.

  1. 01
    Interpret the question

    Resolve the patient, trial, requested decision, and missing facts.

  2. 02
    Retrieve in parallel

    Dispatch Foundry, Fabric, Work, and Web context requests concurrently.

  3. 03
    Match evidence to criteria

    Separate met criteria from blockers, uncertainty, and required follow-up.

  4. 04
    Draft a governed next action

    Return citations, an owner, and a task that remains drafted and unsubmitted.

Evidence you can inspect

01 / Trace

Citations and assessment steps stay visible.

Findings link back to their source material, while the assessment trace shows the specialist queries, deepening, reconciliation, and governed composition steps.

  • Source-level evidence for every material finding
  • Visible retrieval and specialist activity
  • Human-readable impact and unresolved issues

02 / Govern

The output ends in review, not automation.

The final assessment distinguishes potential match from confirmed eligibility, makes open issues prominent, and assigns a next action without submitting a task or sending a message.

Designed to be honest about its boundaries

01

Mock-first by default

The complete local walkthrough runs against deterministic synthetic data without an Azure account, authentication, or live service access.

02

No automatic action

Tasks are drafted, not submitted. No Planner item, To Do task, Teams message, or Work IQ write is created by the application.

03

No clinical claim

The cohort, protocols, identities, and assessments are fictional. The demo is not validated for patient care, trial enrollment, or clinical decision support.
